# 提示词收藏夹

一个无需账号的 Chrome 扩展，支持新增、编辑、删除、搜索和复制提示词，以及单条、勾选多条或全部导出。

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件夹。
4. 点击浏览器工具栏的扩展图标，在独立可移动窗口中打开三栏工作台；可通过拼图按钮将其固定。再次点击图标会切换到已经打开的窗口。

## 导入与备份

导出文件为 JSON，可以通过“导入”重新导入。同一条记录重复导入时按 ID 跳过，不覆盖现有内容。也可以导入 JSON 数组，或包含 `prompts` 数组的对象；每条记录需有字符串 `title` 和 `content`，可选 `tags` 字符串数组。

数据仅存储在当前浏览器的本地扩展存储中，不会自动跨设备同步。卸载扩展或清除扩展数据可能导致数据丢失，请定期导出备份。

兼容常见字段名：标题可使用 `title`、`name` 或 `标题`；内容可使用 `content`、`prompt`、`text`、`body`、`template` 或 `内容`。支持数组以及 `prompts`、`data`、`items`、`collections`、`groups` 等常见容器嵌套。没有标题时使用内容的第一行作为标题。按标题和内容跳过重复项。

## 多级分类

在“分类目录”中选择“全部提示词”或“未分类”，点击“新建分类”创建一级分类；选中已有分类后点击“新建分类”即可创建子分类，可以继续嵌套。新建或编辑提示词时，可在“所属分类”中选择目录。点击分类后显示它的直接子分类和当前层的提示词；点击上方路径可返回上一级。删除分类会将该分类及子分类中的提示词移至未分类，不会删除提示词。导出和导入会保留分类路径；导出全部还会保留空分类。

白无常备份中的分类会在导入时创建为一级分类。之前已经导入的提示词可通过编辑选择分类。

## 拖拽整理

从左侧拖动分类到另一个分类，可将整个分类及其中的子分类、提示词一起移动；拖到“全部提示词”可移到一级。拖动中间的提示词卡片到左侧分类或“未分类”，即可移动提示词。也可以将网页或其他应用中的纯文本拖入中间区域或左侧具体分类，在弹出的编辑框确认并保存。
## 排序与快捷入口

将鼠标移到分类上，使用上下箭头调整同级分类顺序。收藏按钮位于提示词详情中。复制提示词时记录使用次数和时间，“最近使用”按最近复制时间排序，“经常使用”按复制次数排序。删除提示词会先移入回收站，可恢复或永久删除；导出备份不包含回收站中的项目，若需要备份请先恢复。

## 效果参考图

新建或编辑提示词时，可点击选择图片、将图片拖入图片区域，或在编辑窗口直接粘贴剪贴板中的图片。每条提示词可保存多张 PNG、JPG、WebP 或 GIF 图片，单张最大 8 MB；可连续添加并逐张移除。图片存储在本地，导出 JSON 时随提示词一同备份，导入该备份可还原图片。图片会增加本地存储和备份文件的大小。

## 组合复制

勾选所需提示词后可切换到其他分类继续勾选；点击“组合复制”可调整顺序、移除条目、选择分隔方式并预览，然后一次复制组合内容。组合复制会为每条参与的提示词记录一次使用。

勾选后，右侧会显示所有选中的提示词及完整内容，可以直接取消选择、调整顺序或清空选择；点击“组合到对话框”后，可查看组合结果并复制。

提示词卡片右侧的上下箭头可调整当前列表中的顺序；在分类或搜索结果中调整会保存到提示词的整体顺序中。最近使用、经常使用和回收站根据时间或次数自动排序，因此不显示手动排序箭头。

相同内容的图片在本地共用存储；同一提示词重复添加时会跳过，添加其他提示词已有的相同图片时会提示共用。左侧“整理重复图片”可整理旧数据并去除同一提示词中的重复引用，回收站中的图片也会保留。仅文件名相同不会判定为重复，防止误删不同图片。导出备份中会包含每条提示词所需的图片。

左侧“图片库”集中展示所有不同的参考图和关联的提示词（包括回收站），点击提示词名称可定位到对应条目，双击图片可查看原图。图片保存在浏览器的扩展本地存储中，不是可自由移动的独立图片文件。在编辑提示词时，使用参考图上的左右箭头可调整显示顺序，点击保存后生效；顺序也会随备份导出。
